# 7. Heatmaps and Tree Maps

**Aim:** Build a matrix-style heatmap and treemap to explore sales patterns.

**Dataset:** `category_sales.csv`.

**Steps**
1. Import the CSV into Power BI Desktop.
2. Add a Matrix: Rows = Category, Columns = Region, Values = Sum of Sales.
3. Use Conditional formatting → Background color to create a heatmap effect.
4. Add a Treemap: Group = Category, Details = SubCategory, Values = Sum of Sales.
5. Save as `07_Heatmaps_TreeMaps.pbix`.

**Expected result:** Color intensity highlights sales by category and region; treemap rectangles show category/subcategory contribution.
