# Data Visualization Assignments — Power BI

All eight DV assignments are designed for **Power BI Desktop**. Import the CSV in each assignment folder using **Home → Get data → Text/CSV**. Follow the folder README to build the visuals.

> These are starter datasets and report-building instructions, not finished Power BI `.pbix` files. Open Power BI Desktop, create the report, and save it as `.pbix` in the corresponding folder. Add screenshots of your finished report after building it.

## Assignments
1. Getting Started — import a retail CSV and create table, bar and line visuals.
2. Data Cleaning — use Power Query to clean missing values, rename columns and set data types.
3. Bar and Line Charts — compare monthly sales and orders.
4. Interactive Dashboard — use slicers for region, category and date.
5. Geo-Visualization — plot sales by country/state/city using map visuals.
6. Pie and Donut Charts — explore Olympic medal shares.
7. Heatmaps and Tree Maps — build a matrix-style heatmap and a treemap.
8. Time Series Forecasting — plot monthly sales and use the Analytics forecast feature where available.
