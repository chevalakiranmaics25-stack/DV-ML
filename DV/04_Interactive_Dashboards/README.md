# 4. Interactive Dashboards with Filters and Slicers

**Aim:** Build a retail dashboard that responds to Region, Category and Date slicers.

**Dataset:** `retail_dashboard.csv`.

**Steps**
1. Import the CSV and confirm OrderDate is Date and Sales/Profit are numeric.
2. Add Card visuals for Total Sales, Total Profit and Order Count.
3. Add a bar chart for Sales by Category and a line chart for Sales by OrderDate.
4. Add slicers for Region, Category and OrderDate.
5. Use Format → Edit interactions to check slicer interactions.
6. Save as `04_Interactive_Dashboard.pbix`.

**Expected result:** One-page dashboard where slicers filter all relevant visuals.
