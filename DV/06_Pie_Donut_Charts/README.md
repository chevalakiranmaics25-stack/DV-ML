# 6. Pie and Donut Charts

**Aim:** Show medal distribution and country share using pie and donut charts.

**Dataset:** `olympic_medals.csv` (illustrative medal counts for visualization practice, not official Olympic results).

**Steps**
1. Import the CSV into Power BI Desktop.
2. Add a Pie chart: Legend = Country, Values = Gold.
3. Add a Donut chart: Legend = Country, Values = TotalMedals.
4. Turn on Detail labels and show category plus percent of total.
5. Save as `06_Pie_Donut_Charts.pbix`.

**Expected result:** Country-wise medal composition and share.
