# 8. Time Series Forecasting and Trend Lines

**Aim:** Visualize monthly sales, add a trend line and forecast future values.

**Dataset:** `monthly_revenue.csv` (illustrative monthly series).

**Steps**
1. Import the CSV and set Date to Date type and Sales to Decimal Number.
2. Add a Line chart: X-axis = Date, Y-axis = Sum of Sales. Set X-axis Type to Continuous if available.
3. In the Analytics pane, add Forecast and choose a forecast length (for example, 3 months) and confidence interval.
4. If Forecast is unavailable for the selected visual/version, use a supported trend line or moving-average measure.
5. Save as `08_Time_Series_Forecasting.pbix`.

**Expected result:** Monthly sales line with forecast or moving-average trend. Forecast availability depends on the visual and Power BI version.
