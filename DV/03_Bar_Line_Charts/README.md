# 3. Bar and Line Charts for Series Data

**Aim:** Compare category sales and monthly sales trends.

**Dataset:** `monthly_sales.csv`.

**Steps**
1. Import the CSV into Power BI.
2. Create a Clustered column chart: Axis = Category, Values = Sum of Sales.
3. Create a Line chart: X-axis = Month, Y-axis = Sum of Sales.
4. Add Data labels and useful tooltips (Sales, Orders).
5. Sort Month by MonthNumber if the month labels are text.
6. Save as `03_Bar_Line_Charts.pbix`.

**Expected result:** A category comparison chart and a chronological sales trend chart.
