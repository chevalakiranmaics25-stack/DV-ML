# 3. Logistic Regression

**Aim:** Classify observations into one of two classes.

**Dataset:** Breast cancer Wisconsin dataset bundled with scikit-learn.

**Algorithm:** StandardScaler followed by LogisticRegression.

**Run:** `python ML/03_Logistic_Regression/main.py`

**Output:** Accuracy, precision/recall/F1 classification report and `output.png` confusion matrix.

**Conclusion:** Logistic Regression estimates class probabilities; scaling helps the optimizer handle features with different numeric ranges.
