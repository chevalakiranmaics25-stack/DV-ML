# 6. Support Vector Machine (SVM)

**Aim:** Build a binary classifier using a Support Vector Machine.

**Dataset:** Breast cancer Wisconsin dataset bundled with scikit-learn.

**Method:** Standardize features and train an RBF-kernel SVC.

**Run:** `python ML/06_SVM/main.py`

**Output:** Accuracy, classification report and `output.png` confusion matrix.

**Conclusion:** SVM finds a decision boundary with a large margin. Feature scaling is important because SVM relies on distances and dot products.
