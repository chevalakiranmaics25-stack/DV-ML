# Machine Learning Assignments

This folder contains nine beginner-friendly ML experiments. Each Python script trains a model, prints useful evaluation output, and saves a plot as a PNG in the same folder when run.

## Setup
`python -m pip install -r requirements.txt`

Run an assignment from the repository root, for example:
`python ML/01_Simple_Linear_Regression/main.py`

Plots are created in the current working directory. Datasets are provided by scikit-learn or generated in the script, so no manual download is needed.

## Assignments
1. Simple Linear Regression — synthetic one-feature regression data.
2. Multiple Linear Regression — diabetes dataset.
3. Logistic Regression — breast cancer classification dataset.
4. Regression with Regularization — compare Linear, Ridge, and Lasso.
5. PCA — reduce Iris features to two dimensions.
6. Support Vector Machine — breast cancer classification.
7. Decision Tree — Wine classification dataset.
8. Naive Bayes — breast cancer classification.
9. K-means — synthetic clustering data.

Each assignment folder contains its own README with objective, method, and expected output files.
