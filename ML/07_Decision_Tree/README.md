# 7. Decision Tree on a Real-World Dataset

**Aim:** Classify wine samples using chemical measurements.

**Dataset:** UCI Wine dataset bundled with scikit-learn.

**Algorithm:** DecisionTreeClassifier with maximum depth 4.

**Run:** `python ML/07_Decision_Tree/main.py`

**Output:** Accuracy, classification report and `output.png` visualization of the fitted tree.

**Conclusion:** Decision trees learn interpretable if/else rules. Limiting depth helps control model complexity.
