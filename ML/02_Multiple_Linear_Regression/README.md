# 2. Multiple Linear Regression

**Aim:** Predict a continuous target using multiple input features.

**Dataset:** Diabetes regression dataset bundled with scikit-learn.

**Algorithm:** Multiple Linear Regression with `LinearRegression`.

**Run:** `python ML/02_Multiple_Linear_Regression/main.py`

**Output:** Prints MAE, MSE and R²; saves `output.png` comparing actual and predicted values.

**Conclusion:** Multiple features are used together to estimate disease-progression measure. The metrics describe prediction error on held-out data.
